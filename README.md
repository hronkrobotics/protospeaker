# ProtoSpeaker

This project is currently under development.

There is a developmental and prototype mono Bluetooth control board made, with development being done currently on thermoforming 3D-printed speaker grill and adding stereo compatibility, as well as a casing .STEP file.

## Casing & Enclosure

- 3D printable casing (compatible with PLA or PETG).
- Designed as a cube box that houses:
  - 1 speaker driver
  - 4 micro-push buttons
  - 1 on/off switch
  - Charging port/circuitry

## Status

- Prototype mono Bluetooth control board completed
- Ongoing development on thermoformed 3D-printed speaker grill
- Stereo compatibility under development
- Casing .STEP file and 3D print files integrated into the design workflow
